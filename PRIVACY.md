# Privacy Policy

Instruction Switcher stores configuration, instruction bodies, exports, runtime descriptors, acknowledgements, and task state locally under `%CODEX_HOME%\\instruction-switcher` unless the operator selects another local path.

The Windows companion connects to the Codex debugging endpoint on the loopback interface to identify the currently selected task. The connection remains on the local machine. The project does not include telemetry, analytics, advertising, remote account services, or automatic uploads.

Import and export actions read or write files chosen by the user. Opening GitHub documentation or release links uses the user's browser.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
