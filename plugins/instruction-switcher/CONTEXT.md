# Instruction Switcher Context

本项目管理 Codex 任务中的可复用指令内容，并为每个任务保存独立的启用选择。

## Language

**指令项**：
用户可独立管理和启用的一段完整指令文本，是任务级启用的最小单元。
_避免_：profile、preset、单独使用的“指令”

**随包指令项**：
配置预设包为保持预设完整性而携带的指令项。它具有完整执行能力，初始候选可见性为隐藏。
_避免_：隐藏指令、私有指令、预设正文

**候选可见性**：
指令项是否进入用户构建自定义配置时的候选范围。它与当前任务是否启用该指令项相互独立。
_避免_：启用状态、删除状态、私有状态

**配置预设**：
用户命名的一组指令项引用及其顺序，可以整体应用到当前任务。
_避免_：profile、preset、单独使用的“组合”

**当前任务配置**：
某个 Codex 任务当前启用的指令项集合，独立于其他任务和配置预设保存。
_避免_：全局启用列表、共享配置

**指令库**：
用户拥有的全局指令项和配置预设集合，所有 Codex 任务都可以读取和调用。
_避免_：任务指令、项目配置（除非明确标记为项目范围）

**指令正文**：
指令项中会被 Hook 注入 Codex 任务的 Markdown/纯文本内容。
_避免_：富文本内容、展示说明

**自定义配置**：
当前任务经过用户逐项调整后形成的启用指令项集合，不再对应某个完整的配置预设。
_避免_：临时预设、全局预设

**默认配置预设**：
用户指定的一个配置预设，新建 Codex 任务发现时自动作为初始当前任务配置。
_避免_：强制配置、所有任务配置
